A make.fun entry for [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e).

`main.ts` (Node 22, stdlib only) writes one original single-line excuse from a home Wi-Fi router — 123 characters — to `/output/entry.txt`:

> You haven't looked at me once in three years — you only notice me when I die — so at the climax tonight, I died on purpose.

Run it with:

```sh
node main.ts
```
